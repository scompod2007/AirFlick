# AirFlick

### Gesture-Based Wireless File Transfer

---

## About

**AirFlick** is a gesture-based wireless file transfer project designed to make file sharing faster, simpler, and more intuitive.

The project explores the use of hand gestures to initiate and authorize wireless file transfers between compatible devices, reducing the need for traditional manual file-sharing workflows.

---

## Features

* Hand gesture-based file transfer
* Gesture PIN for transfer authorization
* Wireless device-to-device communication
* High-speed file transmission
* Simple and intuitive interaction
* Secure sharing mechanism
* Designed for efficient file sharing

---

## Concept

```text
             Hand Gesture
                  |
                  v
          Gesture Recognition
                  |
                  v
            Gesture PIN
                  |
           Authorization
                  |
                  v
          Device Detection
                  |
                  v
        Wireless Connection
                  |
                  v
            File Transfer
```

AirFlick uses a **Gesture PIN** as an additional authorization mechanism for secure file sharing.

Instead of relying only on device detection, the sender performs a predefined sequence of hand gestures that acts as a Gesture PIN. Once the gesture sequence is successfully recognized and authorized, AirFlick establishes the wireless connection and initiates the file transfer.

The gesture acts as the interaction and authorization layer, while the underlying wireless communication handles the actual file transmission.
